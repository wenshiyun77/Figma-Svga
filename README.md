# Figma SVGA Editor Plugin

Independent Figma plugin project for turning Figma canvas layers into `.svga` files directly inside Figma.

## Why this is separate

This project is intentionally outside `svgavap-lab`. It is a standalone Figma plugin: no local service, no client folder coupling, and no network access.

The plugin UI does not include AI generation features. It only reads the current Figma selection, edits simple per-layer animation settings, and exports SVGA.

## Load in Figma

In Figma, import the plugin by selecting:

```text
Plugins > Development > Import plugin from manifest...
```

Then choose:

```text
figma-svga-editor-plugin/manifest.json
```

`manifest.json` includes a fixed development `id` so `figma.clientStorage` can persist the free export count and license state. Before publishing a real Community/private plugin build, replace that `id` with the one generated by Figma's plugin publishing flow.

## Canvas and layer mapping

- If you select one Frame, Component, Instance, Component Set, or Section, that node becomes the SVGA canvas.
- The SVGA `viewBoxWidth` and `viewBoxHeight` match that Figma canvas size.
- The plugin recursively exports the selected canvas node's visible descendants as SVGA image sprites.
- Text, image-filled shapes, vector, and basic shape nodes are all imported by rasterizing each element to a PNG-backed sprite.
- Rotated and mirrored Figma layers are imported as the final rasterized visual shown in Figma, without preserving editable rotation or mirror metadata.
- The plugin reads each imported Figma layer's name, node id, type, absolute bounds, and canvas-relative bounds.
- Each sprite's size matches the imported Figma layer's final visual bounds.
- Each sprite's position is relative to the Figma canvas origin.
- If you select several elements inside the same Frame, the shared parent Frame becomes the SVGA canvas and only the selected elements are exported.
- If no parent Frame can be found, the plugin falls back to the selected elements' bounding box.
- The plugin preview uses the imported canvas pixel size as its actual DOM size, so layer placement is shown 1:1 inside a scrollable viewport.

## Layer refresh

- When the plugin opens with a valid Figma selection, it automatically syncs the selection once.
- The `同步当前选区` button manually rebuilds the whole imported canvas from the current Figma selection.
- Imported layers keep their source Figma node id, so later changes in Figma can be checked against the same layer.
- The plugin listens for Figma document changes and also polls the imported nodes.
- If an imported Figma layer changes, the matching row is highlighted as `已变化`.
- The `更新` button on that row re-exports only that Figma layer and keeps the existing animation settings.

## Workflow

1. Select a Figma Frame to export the whole canvas, or select specific elements inside one Frame.
2. Run `SVGA Editor`.
3. The plugin automatically syncs the current selection. Use `同步当前选区` if you change the selection.
4. Select a layer and choose `float`, `swing`, `pulse`, or `spin`.
5. Click `导出 SVGA`.

The plugin includes 10 free exports per installation. After that, the user sees the embedded contact QR code and an authorization ID. You can issue an offline signed license code with:

```bash
npm run license:code -- --customer "客户名" --installation-id "figma-xxxx" --days 365
```

## Checks

```bash
npm run check
```

The check validates `manifest.json`, parses plugin JS, and parses the inline UI script.

## MVP limits

- The plugin exports Figma nodes as PNG-backed SVGA sprites. It does not preserve editable vector or text layers inside SVGA.
- The embedded encoder uses an uncompressed zlib block, so output files can be larger than the current app exporter.
- Advanced effects such as sweep, particles, masks, and sequence sheets are roadmap items.

## License setup

Before publishing your own build, generate a private signing key and embed its public key:

```bash
npm run license:keygen
```

Keep `license-private-key.pem` private. See [docs/license.md](docs/license.md).
