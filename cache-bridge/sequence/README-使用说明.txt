雪碧图拆帧工具 v1.1.0（画布直拖 / 粘贴版）

一、打开方式
在 macOS / Windows 中解压，然后使用最新版 Chrome 打开“雪碧图拆帧工具.html”。无需安装软件或联网服务器，界面功能在浏览器本地运行。

二、导入图片
1. 在网页或图片软件里“复制图片”，切回工具直接按 Cmd+V（Mac）/ Ctrl+V（Windows）。
2. 可把本地 PNG、JPG、GIF、WebP、APNG 直接拖到中间画布的任何位置。
3. 空画布可以单击后选择本地图片。
4. 对网页中仅复制出来的 <img src> / 图片 URL，工具会尝试从原地址获取图片。受原网站跨域 CORS 或权限保护时，浏览器无法获取，建议“复制图片”实际位图，或把原始文件保存后拖入。

三、动态图拆帧
GIF 可在本地逐帧解码；动态 WebP/APNG 依赖 Chrome/Edge 的 WebCodecs ImageDecoder 支持。导入动态图后自动读取各帧、按原始帧顺序在画布里排列、推荐接近方形的列数、尽可能保留各帧时长。修改列数时不会打乱动态图的原始素材。
目前最多支持 300 帧；非常大的帧或高分辨率动画可能触发内存保护提示。
注意：网页“复制图片”有时只复制当前静态画面；如需拆出完整动画，请拖入原始 GIF/WebP/APNG 文件，或从网页获取原始文件链接（需网站允许读取）。

四、编辑与导出
- 画布：切片选中，鼠标拖动位置、方向键微调（Shift+方向键为 10px）。
- Shift 依次点选多个切片，可按点选先后批量排序、共同缩放，以各帧中心为锚点。
- 擦除模式：选择橡皮大小，画布拖动擦除单帧像素；Cmd+Z / Ctrl+Z 撤回。
- 标尺/参考线不会进入导出。
- 导出 PNG 序列 ZIP、动态 WebP 或 GIF（GIF 透明度只能是透明/不透明两档，受格式本身限制）。
- 导入动态图时预览及 GIF/WebP 导出优先保留原始每帧时长；静态雪碧图使用设置的 FPS。

五、版本核对
正确版本在页面左上标题旁显示 v1.1.0，左侧没有“雪碧图”上传框；“动画预览”在“当前切片”上方。

六、离线说明
本工具是单 HTML，不上传素材。通过网页图片 URL 导入时，浏览器会直接访问该 URL。浏览器跨域限制不能由本地工具绕过。
