SVGA Editor Support

SVGA Editor creates short looping animations from image assets inside ChatGPT.

Supported inputs

PNG, JPEG, WebP and GIF. Animated inputs currently use the first decoded frame.

Supported exports

SVGA, GIF and animated WebP.

Common issues

If preview loading fails, retry with the image attached directly to the chat. If export is slow, reduce FPS or use a smaller source image.
