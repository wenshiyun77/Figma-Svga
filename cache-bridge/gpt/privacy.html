Privacy Policy

Last updated: October 2, 2026.

SVGA Editor processes image file references supplied by ChatGPT in order to preview and export animations. The MVP does not require an SVGA Editor account and does not sell personal data.

Processing

Animation rendering is performed in the ChatGPT plugin UI in the user's browser. The MCP server receives file identifiers and animation settings needed to initialize the workflow. It does not need to permanently store the source image for the MVP.

Generated files

Generated files may be uploaded to ChatGPT using ChatGPT's file APIs when available so the user can download them. Those files are then governed by the applicable ChatGPT file handling terms.

Operational logs

The hosting platform may retain standard request metadata and error logs for security, reliability and debugging.
