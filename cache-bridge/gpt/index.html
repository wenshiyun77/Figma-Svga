SVGA Editor / ChatGPT Plugin

Add motion to design assets directly in ChatGPT.

Upload an image, choose an effect, preview it in ChatGPT, and export SVGA, GIF or animated WebP. The first release focuses on fast 1-6 second transparent asset animations.

EffectsVIP combo, shine, glow, particles, fade, pulse and float.
PreviewInteractive browser-side preview with duration, FPS, intensity and accent controls.
ExportSVGA, GIF and animated WebP. Rendering happens locally in the plugin UI.
